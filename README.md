# EB-5 Global Capital Clone 🚀
A high-performance, pixel-perfect clone of the EB-5 Global Capital website built with **React.js** and **Vite**.
Developed by: Shah Alam
### ✨ Features:
- **Heavy Drop Animations:** Custom CSS animations for a "falling impact" effect.
- **Auto-Switching Cards:** Synchronized text and image transitions in the Projects section.
- **Smooth Navigation:** Interactive SideNav with active section detection.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop.
- **Glassmorphism UI:** Premium transparent layouts with backdrop filters.

### 🛠️ Tech Stack:
- React.js (Vite)
- Tailwind CSS
- Custom CSS (for complex animations)
